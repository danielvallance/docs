This guide explains how to create and deploy a simple Perl-based HTTP web server.
To run this example, follow these steps:

1. Install the CLI and a container runtime engine, for example [Docker](https://docs.docker.com/engine/install/).
   Use the [unikraft CLI](/docs/cli/unikraft) or the legacy [kraft CLI](https://unikraft.org/docs/cli/install).

1. Clone the [`examples` repository](https://github.com/kraftcloud/examples) and `cd` into the `examples/http-perl5.38/` directory:

```bash
git clone https://github.com/kraftcloud/examples
cd examples/http-perl5.38/
```

Make sure to log into Unikraft Cloud and pick a [metro](/metros#available) close to you.
This guide uses `fra` (Frankfurt, 🇩🇪):

<CodeTabs syncKey="cli-tool">

```bash title="unikraft"
unikraft login
```

```bash title="kraft"
# Set Unikraft Cloud access token
export UKC_TOKEN=token
# Set metro to Frankfurt, DE
export UKC_METRO=fra
```

</CodeTabs>

The `UKC_TOKEN` and `UKC_METRO` environment variables are only supported by the legacy CLI.

When done, invoke the following command to deploy this app on Unikraft Cloud:

<CodeTabs syncKey="cli-tool">

```bash title="unikraft"
unikraft build . --output my-org/http-perl538:latest
unikraft run --metro=fra -p 443:8080/http+tls -m 512MiB my-org/http-perl538:latest
```

```bash title="kraft"
kraft cloud deploy -p 443:8080 -M 512 .
```

</CodeTabs>

## Customize your app

To customize the app, update the files in the repository, listed below:

* `server.pl`: the actual Perl HTTP server
* `Kraftfile`: the Unikraft Cloud specification
* `Dockerfile`: the Docker-specified app filesystem

<Tabs defaultValue="kraftfile">
  <TabsContent  value="server.pl">
    ```pl
    #!/usr/bin/perl

    use warnings;
    use strict;

    use HTTP::Daemon;
    use HTTP::Status;
    use HTTP::Response;

    my $daemon = HTTP::Daemon->new(
            LocalAddr => '0.0.0.0',
            LocalPort => 8080,
    ) or die;

    while (my $client_connection = $daemon->accept) {
            my $request = $client_connection->get_request;
            my $response = HTTP::Response->new(200);
            $response->content("Hello, World!\n");
            $client_connection->send_response($response);
    }
    ```
  </TabsContent>
  <TabsContent  value="Kraftfile">
    ```yaml
    spec: v0.6

    runtime: perl:5.38

    rootfs: ./Dockerfile

    cmd: ["/usr/bin/perl", "/usr/src/server.pl"]
    ```
  </TabsContent>
  <TabsContent  value="Dockerfile">
    ```dockerfile
    FROM scratch

    # Simple Perl HTTP server
    COPY ./server.pl /usr/src/server.pl
    ```
  </TabsContent>
</Tabs>

The following options are available for customizing the app:

* If you only update the implementation in the `server.pl` source file, you don't need to make any other changes.

* If you create any new source files, copy them into the app filesystem by using the `COPY` command in the `Dockerfile`.

* More extensive changes may require extending the `Dockerfile` ([see `Dockerfile` syntax reference](https://docs.docker.com/engine/reference/builder/)).
