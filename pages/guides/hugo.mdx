This guide shows you how to use [Hugo](https://gohugo.io/commands/hugo_server/), a high performance webserver, with the [ananke](https://github.com/budparr/gohugo-theme-ananke.git) theme.

To run it, follow these steps:

1. Install the CLI and a container runtime engine, for example [Docker](https://docs.docker.com/engine/install/).
   Use the [unikraft CLI](/docs/cli/unikraft) or the legacy [kraft CLI](https://unikraft.org/docs/cli/install).

1. Clone the [`examples` repository](https://github.com/kraftcloud/examples) and `cd` into the `examples/hugo/` directory:

```bash
git clone https://github.com/kraftcloud/examples
cd examples/hugo/
```

Make sure to log into Unikraft Cloud and pick a [metro](/metros#available) close to you.
This guide uses `fra` (Frankfurt, 🇩🇪):

<CodeTabs syncKey="cli-tool">

```bash title="unikraft"
unikraft login
```

```bash title="kraft"
# Set Unikraft Cloud access token
export UKC_TOKEN=token
# Set metro to Frankfurt, DE
export UKC_METRO=fra
```

</CodeTabs>

The `UKC_TOKEN` and `UKC_METRO` environment variables are only supported by the legacy CLI.

When done, invoke the following command to deploy this app on Unikraft Cloud:

<CodeTabs syncKey="cli-tool">

```bash title="unikraft"
unikraft build . --output my-org/hugo:latest
unikraft run --metro=fra -p 443:1313/http+tls -m 512MiB my-org/hugo:latest
```

```bash title="kraft"
kraft cloud deploy -p 443:1313 -M 512 .
```

</CodeTabs>

## Customize your app

To customize the Hugo app, update the files in the repository, listed below:

* `Kraftfile`: the Unikraft Cloud specification
* `site/`: sample site content
* `Dockerfile`: In case you need to add files to your instance's rootfs

<Tabs defaultValue="kraftfile">
  <TabsContent  value="Kraftfile">
    ```yaml
spec: v0.6

runtime: hugo:latest

rootfs: ./Dockerfile

cmd: ["/usr/bin/hugo", "server", "--bind=0.0.0.0", "--source", "/site"]
    ```
  </TabsContent>
  <TabsContent  value="Dockerfile">
    ```dockerfile
FROM debian:bookworm AS build

RUN set -xe; \
    echo "Your code here";

FROM scratch

COPY site /site
    ```
  </TabsContent>

</Tabs>

Update the contents of the `site/` directory to serve different static web content.

After re-deploying the Hugo image on Unikraft Cloud, using `curl` or a browser to query it will present the new page contents.

Tools like [`Jekyll`](https://jekyllrb.com/) or [`Hugo`](https://gohugo.io/) can generate the static web content located in the `site/` offline.
